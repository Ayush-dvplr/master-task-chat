# Spectral covariance audit contract

The extract describes repaired covariance-like matrices for six named variables, four cohorts, three periods, and four independent sources. Observations are decimal covariance estimates. The fixed variable order is hydra, kepler, lyra, orion, pavo, vega. The fixed cohort order is Arden, Beryl, Canto, Dorian. The fixed source order is atlas, beacon, cygnus, draco. The fixed period order is 2026Q1, 2026Q2, 2026Q3. A valid report applies authoritative ledger corrections, per-source and per-period calibration, anchor-derived source bias, weighted cross-source reconciliation, state-edge propagation, symmetry convergence, diagonal floors, off-diagonal caps, deterministic sorted JSON serialization, and output-level cohort/source/variable summaries. All ppm fields are rounded to nearest-even integer parts per million. Every mean or summary statistic (global mean, diagonal mean, cohort mean, period mean, and per-variable diagonal mean, min, and max) is computed from the full-precision decimal cell values and rounded to nearest-even ppm exactly once at output; do not average the already-rounded ppm integers written into the matrix artifacts.

The reusable program must accept DATA_DIR and OUT_DIR. It must discover its inputs by file family inside DATA_DIR rather than by fixed absolute input paths. The families that feed the reconciliation are exactly these: `params.json` for the numeric bounds and rounding mode, `source_priors.csv` for per-source priors, `calibration_<source>.csv` for per-source and per-period calibration, `anchor_constraints_<source>.csv` for anchor rows, `state_edges_<period>.csv` for state edges, `ledger_corrections_<cohort>.csv` for ledger actions, and `field_observations_<cohort>_<period>.csv` for the observations themselves. No other file feeds a reported value. In particular `sample_observations.csv` is a single illustrative row showing the observation column layout and must be excluded from the corpus, and `schema.md`, `reconciliation_scope.txt`, `review_note_*.txt`, `cohort_manifest_<cohort>.csv` and `variable_manifest_<variable>.csv` are descriptive only; they are still counted by the input_files total described below. The program must write JSON with sort_keys true, compact separators, and one trailing newline.

Source bias is computed for each source by averaging target_ppm minus observed_ppm across that source's anchor rows, divided by 1000000 for internal decimal use. The source_bias_ppm report values are that mean expressed in ppm and rounded to the nearest even integer, where the rounding is decided on the exact mean of the integer target_ppm minus observed_ppm differences, so a mean that lands exactly on half a ppm goes to the even neighbour regardless of how the decimal bias is carried internally. Anchor_counts records the number of anchor rows for each source.

Ledger corrections are matched by observation_id before calibration. A void ledger row removes that observation and records an event with observation_id and effect set to voided. A replace ledger row substitutes replacement_value and replacement_reliability_bps before calibration and records observation_id, effect set to replaced, before, and after.

For each remaining observation, corrected value equals raw_value times scale_ppm divided by 1000000 plus offset_ppm divided by 1000000 plus the source bias for that source. Observation weight equals reliability_bps divided by 10000 times the source prior_bps divided by 10000 times the calibration stability_bps divided by 10000. The local estimate for each cohort, period, var_i, var_j cell is the weighted average of corrected values for that cell.

Each state edge uses source cell from_cohort, period, var_i, var_j and destination cell to_cohort, period, var_i, var_j. If both cells exist, propagated value equals source estimate times multiplier_ppm divided by 1000000 plus delta_ppm divided by 1000000. The destination estimate becomes the average of its prior value and the propagated value. Each applied edge records edge_id, before_ppm, after_ppm, and propagated_ppm.

For every cohort and period, build a 6 by 6 matrix in the fixed variable order. For each upper-triangle pair, average any available estimate for var_i,var_j and the reverse pair. If neither exists, use 1.0 on the diagonal and 0.0 off the diagonal. Diagonal cells must be at least diagonal_floor_ppm divided by 1000000. Off-diagonal cells must be clipped to plus or minus offdiag_abs_cap_ppm divided by 1000000. Copy each upper-triangle value to the mirrored lower-triangle cell. Matrix JSON values are nearest-even rounded ppm integers.

Required JSON shapes are fixed. matrix_all.json maps each cohort to each period to a 6 by 6 integer matrix. global_summary.json has keys cohorts, periods, variables, global_mean_ppm, diagonal_mean_ppm, ledger_events, and state_edges. cohorts is the count of cohorts and periods is the count of periods. variables is the list of variable names in the fixed variable order. global_mean_ppm is the nearest-even ppm mean of all upper-triangle matrix cells across all cohorts and periods. diagonal_mean_ppm is the nearest-even ppm mean of all diagonal cells across all cohorts, periods, and variables. ledger_events is the count of recorded ledger events. state_edges is the count of applied state edges.

audit_state.json has keys source_bias_ppm and anchor_counts, and each of them maps every source name to that source's value. dependency_checks.json has keys observation_cells, calibration_keys, anchors, constraints_applied, and complete. observation_cells is the count of local estimate cells after ledger handling. calibration_keys is the count of source-period calibration entries. anchors is the count of anchor rows. constraints_applied is the count of applied state edges. complete is true only when every cohort, period, and diagonal variable cell has an estimate after ledger handling.

cohort_Arden.json, cohort_Beryl.json, cohort_Canto.json, and cohort_Dorian.json each have keys cohort, mean_ppm, and periods. mean_ppm is the nearest-even ppm mean of that cohort's upper-triangle matrix cells across all periods. periods maps each period to that cohort-period 6 by 6 integer matrix.

source_atlas.json, source_beacon.json, source_cygnus.json, and source_draco.json each have keys source, bias_ppm, prior_bps, and relative_rank. bias_ppm is the source bias in ppm. prior_bps is read from source_priors.csv. relative_rank is one-based rank by descending prior_bps.

variable_hydra.json, variable_kepler.json, variable_lyra.json, variable_orion.json, variable_pavo.json, and variable_vega.json each have keys variable, diagonal_mean_ppm, diagonal_min_ppm, and diagonal_max_ppm computed from the variable's diagonal matrix cells across all cohorts and periods.

convergence_periods.json has key period_mean_ppm, mapping each period to the nearest-even ppm mean of upper-triangle matrix cells for that period across all cohorts. convergence_constraints.json has keys max_abs_edge_shift_ppm and edge_count. max_abs_edge_shift_ppm is the maximum absolute difference between after_ppm and before_ppm across applied state-edge residuals, or 0 when no edge is applied. edge_count is the number of applied state edges.

eigen_spectrum.json has key gershgorin_radii_ppm. It maps each cohort to a list of three values in period order. Each value is the nearest-even ppm maximum row sum of absolute decimal matrix values for that cohort-period matrix. residuals.json has key edge_residuals with the applied edge records. ledger_effects.json has key events with ledger event records. reproducibility.json has keys serialization, input_files, and artifact_count. serialization must equal json-sort-compact-newline. input_files is the count of immediate files in DATA_DIR. artifact_count must be 25.
