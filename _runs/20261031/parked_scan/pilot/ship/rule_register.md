# Rule Register

Every rule of this review is written in one governing file. Where two files seem to disagree, the
governing file in this table decides.

| topic | governing file and section |
|---|---|
| visits, times, the movements log layout | `tariff_circular.md` section 1 |
| the due, rounding, surcharge, holidays | `tariff_circular.md` section 2 |
| on-board and billed minutes | `tariff_circular.md` section 2a |
| listed tariff values | `tariff_circular.md` section 3 |
| tariff periods and notices | `tariff_circular.md` section 4 |
| recovering a station's tariff | `tariff_circular.md` section 5 |
| verdicts, reasons, the disputed batch layout | `tariff_circular.md` section 6 |
| paid invoice file layouts | `tariff_circular.md` section 7 |
| notice dates, call-out fees, minimum dues | `station_notices.md` |
| segments, certificates, the vessel register layout | `exemption_policy.md` |
| records, rejected records, superseded invoices, fatal inputs, values, output documents | `output_contract.md` |
