# Rule register

Every rule of this review is written in one governing file. Where two files seem to
disagree, the governing file in this table decides.

| topic | governing file |
|---|---|
| log records, visits, draft, tonnage | tariff_circular.md section 1 |
| due lines, rounding, surcharge hours, marks | tariff_circular.md section 2 |
| listed tariff values | tariff_circular.md section 3 |
| periods | tariff_circular.md section 4, station_notices.md |
| station conventions, tariff of a period | tariff_circular.md section 5 |
| disputed invoices, verdicts | tariff_circular.md section 6 |
| paid invoice file layouts | tariff_circular.md section 7 |
| holiday calendars | holidays.json |
| segments, certificates, exemption | exemption_policy.md |
| rejected records, fatal inputs, values, output documents | output_contract.md |

Data files: `pilot_movements.log`, `vessel_register.tsv`, `certificates.json`,
`holidays.json`, `station_notices.md`, `paid_north.csv`, `paid_south.jsonl`,
`paid_west.txt`, `paid_east.xml`, `disputed_batch.csv`.
