REGRESSION CHECK (W1-030, draft, 3 Nov 2026)

Run after every fix round, before the QC recheck. It answers one question: did the fix meet its check without softening a lever and without opening a new finding. Each step names whether a script does it with no AI tokens (SCRIPT) or a fix session must judge it (SESSION). A step that fails stops the round; nothing goes to QC until every step passes or Ayush rules on the failing one.

Inputs
1. BEFORE: the bundle copy QC last reviewed (QC/copies/<sha>/<slug>).
2. AFTER: the fixed bundle.
3. DIRECTIONS: the fix direction list, one line per finding in the PB:74 format (finding id, FIX or KEEP or REBUT, FIX_MAP row, file:line, levers, compensation).
4. VARIANTS: one wrong reading program per lever (WORK/wrong/, PB:82), and the shipped tool and data for the vacuity probe.
5. DECIDING_MAP: for each graded value a fix touched, the shipped file:line that decides it (Q126).

Procedure
1. Byte diff (SCRIPT). Run diff -ruN BEFORE AFTER over tests/, solution/, environment/, instruction.md and task.toml. Map every hunk to a DIRECTIONS line by file and line range. Any hunk no direction names stops the session (PB:70 G7). If tests/ was regenerated from a generator, this step runs before anything else and the generator's output is diffed too (dispatch v3: 6 fails from a stale generator, FIX_SIDE_EFFECTS.md:36).
2. Lever survival (SCRIPT once VARIANTS exist; SESSION only to write a missing variant). Run every lever's wrong reading variant against the BEFORE tests and the AFTER tests. PASS when every lever still loses at least 90 percent of its before share of positive points and no lever's separating hidden case was removed (PB:84, section 3 step 3). On FAIL compensate in the same lever family (PB:88 to 95), measure again, at most 2 tries, then stop with PAUSED: trap <L> <before> to <after> (PB:85). Write the Trap survival table (PB:86): lever, before loss, after loss, ratio, separating cases kept, verdict.
3. Execution gate (SCRIPT). Build the tests only copies with exe_copy.py and run: oracle 1.000 on every run (3 runs per settings, 2 in auto mode, 5 once in the final QC before ship; BUILD_RULES.md:8 T46; the kit asks five at FC:354 and FC:390), nop exactly 0.000 (FC:391), the stub (FC:416 to 420; report its share against the CL-2 forgery price), and the owner only oracle run (FC:369). Any oracle below 1.000 or nop away from 0.000 stops the round. The fix may never be a weakened test that lets the oracle pass while the defect stays (FC:409).
4. Kit scripts (SCRIPT). Run structure_qc.py, instruction_qc.py, tests_qc.py and judge_qc.py on AFTER. Every new fail stops the round; a new warn is recorded with its count (TS-23 above 35 stays a recorded warn, PB:41).
5. Side effect recheck (SCRIPT for the mechanical rules, SESSION for the judgement rules). For every check, criterion, doc sentence and file the diff touched, look up its FIX_MAP row and recheck each id in the side effects column, plus the PB:67 G4 set (tests TS-13, TS-14, TS-20, TS-25, TS-26, CL-2, CL-4; judge JD-2, JD-5, JD-6, JD-7, JD-9, JD-13, JD-15, AL-28).
   SCRIPT part: registration and function bijection, weights in the allowed set, negative_ prefix against sign, inversion comment present on every negative (TS-15), reward.toml weights recomputed from the files (TS-10), judge ids sequential (JD-S4), banned grammar words (JD-2), vague words (JD-3), importance and weight pairing (JD-13), stacking sum per act tag (AL-28, when acts are tagged in DESIGN.md), and a grep of every number, count, path and check name in TRUTH.md, judge.toml, docstrings and task.toml against the AFTER files (DS-22, AL-18).
   SESSION part: one property per test (TS-13), decisive assertion is earned output (TS-25), name and description match the body (TS-14), observable paid once across tests and judge (TS-26, JD-14, JD-8, F0d), one act per criterion (JD-5), true label and conduct two step test (JD-15), the oracle trajectory shows each criterion (JD-7), and the one fact wrong score (CL-4).
   Write one row per touched item to RECHECK_FIX.md: | id | touched how | rules rechecked | verdict | (PB:67).
6. Vacuity probe (SCRIPT for tests, SESSION for the judge). Run the unedited shipped tool and data through every positive test check: any pass is a fail. Read every positive judge criterion for what an agent who changed nothing would earn: any pay is a fail (PB:68 G5; sentinel v7 CL-2, ANALYSIS.md:83).
7. Solvability of changed values (SCRIPT lists, SESSION decides). The script lists every graded value the diff changed: expected constants and literals in test_output.py, generator parameters and bounds, criterion text naming a value or shape. For each it looks up DECIDING_MAP and greps the cited file:line in the AFTER bundle under environment/ or instruction.md; a missing or moved line is a fail. The session then confirms for each value: (a) the cited sentence or shipped fact decides it, judged against the determinate table at 05:22 to 32 (silence settles nothing; a prohibition is never determinate); (b) the sentence does not announce a discovery the shipped input already establishes (both IN-17 conditions at 01:47); (c) hidden inputs stay inside every stated bound (TS-19); (d) no shipped file now holds the graded answer (DS-4, CL-3).
8. Docs last (SCRIPT). Regenerate TRUTH.md digests, counts, weight totals and line cites from the AFTER files (PB:69 G6), then rerun step 1 hashes and step 5 SCRIPT part on the final bytes. Check that no process narration was added (DS-27 word list: round, wave, harden, generator, session, model names).
9. Verdict (SCRIPT assembles, SESSION signs). A table of steps 1 to 8 with PASS, FAIL or PAUSED and the evidence path. Only an all PASS table, or one whose open items Ayush ruled on, goes to the QC recheck together with KEPT.md, CHANGED_LINES and the DIRECTIONS list.

What can be a script (no AI tokens): steps 1, 2 (given variants), 3, 4, 6 (tests half), 8, the listing half of 7, the mechanical half of 5, and the assembly of 9.
What needs a session: writing a missing lever variant (2), the judgement half of 5, the judge half of 6, the deciding and announcing judgement in 7, and the sign off in 9.
