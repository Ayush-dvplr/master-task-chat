Removing the 9 sentences will not move the tests much; it is hygiene, not hardness.

Proposed BUILD_RULES text.
BR-SL1 State the decider, never the walk. Each graded value is decided by one sentence that names its inputs, its condition and its result: a definition, a formula, a precedence list, or an objective with its tie break. An order is written only when the order itself decides the value (a precedence list, a payment order, a tie order). Never write how a program finds the value: no search range or method beyond the stated domain, no pass by pass narration, no pseudo code, no worked example on shipped or hidden values (W6 toy examples stay as they are).
BR-SL2 One decider per value. When a value is decided, delete every second sentence about it: a restatement from the other side ("the allowance never changes which plan is optimal" after "After the season plan is fixed"), a sentence that names a wrong reading ("whichever base it is at"), and a coupling restatement ("every figure is taken from the single plan that is optimal for all four depots together") when the objective and the shared limit already decide it.
BR-SL3 Decide, do not reassure. Replace an assurance ("the settlements fit exactly one k") with a deciding rule that covers the case it hides ("when more than one k fits, the smallest is used"), or drop it when the generator guarantees one fit and the deciding sentence already reads one way.
BR-SL4 Prefer evidence to prose where it is legal. For at least one lever, state the candidate family in a sentence (DS-21) and let a determinate shipped fact in another file select the member (EVIDENCE_MAP, Common rule 6), as TB does with calibration figures and TA with settlement logs. The family sentence is required; the member is never written.
DR3 check: none of these removes a deciding sentence. BR-SL2 deletes only text whose value is already decided elsewhere in the same file set; BR-SL3 replaces an assurance with a decider; BR-SL4 keeps the family sentence and moves only the member to determinate evidence that Common rule 6 already allows.
