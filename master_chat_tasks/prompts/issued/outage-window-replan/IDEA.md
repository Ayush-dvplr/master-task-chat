## Setting
A transmission operator replans a season of planned maintenance outages across four regions (North, South, West, East). Each outage request names a line or transformer, a duration in whole days, an earliest start and latest finish, a crew type, and the customers it puts at risk (commercial or public: hospitals, water, schools). Crews per type per region per day are limited; some assets cannot be out together (a stated incompatibility list, e.g. parallel circuits), some outages must follow others (stated precedence), and region-wide blackout days (holidays, peak-load days) forbid starts. A disruption notice (crew loss on given days, a new urgent request) arrives after a published plan; the agent's program must re-solve and publish the replanned season.

The objective is stated exactly and lexicographically, so the optimum is unique: (1) minimise total weighted risk-days (risk weight per customer class times days out, stated table), (2) then minimise the number of outages moved from the published plan, (3) then the stated tie-break (earliest start in asset-id order). A request that cannot be placed is deferred with a stated reason string and a stated penalty that enters objective (1).
