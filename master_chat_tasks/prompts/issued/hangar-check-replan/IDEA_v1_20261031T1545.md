## Setting
An airline maintenance planner replans the heavy-check season (A/C/D checks) for a fleet across four bases (North, South, West, East) after a disruption notice (a hangar bay closed on given days, an aircraft returned early or grounded). Each check request names the tail number, check type, duration in whole days, earliest start and latest finish (regulatory due date), the bay type it needs, and the revenue cost per day the aircraft is out (by aircraft class: widebody, narrowbody, regional, stated table). Each base has bays per type per day; two checks that share the same tooling set cannot overlap at a base (stated list); some checks must follow others on the same tail (stated precedence); base blackout days forbid starts.

Global coupling (the lever): the operation has ONE fleet-wide limit on overtime crew-shifts for the season (stated number) and a stated rule for how many overtime shifts a check uses when it is compressed (a check may be compressed by up to its stated number of days, each compressed day costs the stated overtime shifts). Overtime is shared by all four bases. Compressing lets a check finish before its due date or avoid a blackout clash.

Objective, stated exactly and lexicographically so the optimum is unique: (1) minimise total overdue-days weighted by the stated class weight (a check finishing after its due date is overdue; a request that cannot be placed is deferred with a stated reason string and a stated penalty in this term), (2) then minimise total out-of-service revenue cost, (3) then minimise checks moved from the published plan, (4) then the stated tie-break (lexicographically smallest list of (start day, tail number)).
