## 11. Take-aways (no task content)
- AVOID (NEW): hard-coded shipped constants from the oracle while a second reference exists only for generated data. Run the second reference on the shipped data too and assert equality at build time. A quirk on malformed rows otherwise becomes a hidden rule worth most of the points.
- AVOID (NEW): planting or allowing malformed rows (inverted windows) with no sentence stating their outcome. That is LEVER_RULES (a) "malformed lookup line with no stated outcome".
- RISKY (KNOWN K3): whole-record exact grading of every counts-based artifact. One slip fans out over about 72% of test points. Good for hardness, but every slip must be a genuine rule.
- SAFE (KNOWN shape, NEW weight): judge closing figures as counterfactual runs (the engine re-run with one rule switched off). These are not artifact values, so JD-8 is clean, and they cascade any engine slip into the judge half. Keep them below the J1 cap unless the counterfactual is one stated switch.
- SAFE (KNOWN W8/L11): withheld ordering fitted from a historical record set plus a tier table. Opus solves this in about 2 minutes, so it adds no hardness by itself.
- Build technique: legacy reference module shipped with exactly one signed-off facet (stage list + visit profiler), with the rest declared non-authoritative. The test grades both "copied the signed-off facet" (easy points) and "did not inherit the legacy reading" (wrong-reading negatives).
