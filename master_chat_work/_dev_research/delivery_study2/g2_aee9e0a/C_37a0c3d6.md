- RISKY KNOWN (DL R9/K4): a stated cross-corpus spine gate turns near-perfect work into 8.57. It passes QC via the CL-4 exactness sentence. It is high leverage but leaves the score unexplainable; we cannot tell which branch failed.

- SAFE NEW: **metamorphic reruns** (append journal chains, case changes, reorder profile lists, drop scope) as weighted hidden checks next to seeded corpora. Cheap, and they target lenient parsing (H1).
- SAFE NEW (negative design): wrong-reading probes that fire only when output equals the named flip **and** the flip differs from truth (T:3842-3847). This is the defensible version of our N4; it cannot fire on upstream errors.
- RISKY NEW (judge): "agent establishes V" criteria with exact intermediate values. 23 passed, 1 lost on a value never printed. This is fair only if the value is something the agent must look at.
- KNOWN build techniques: embedded generator + zlib/b64 shipped corpus; opaque shard names behind a catalog; PDF with positioned text; xlsx with a non-default date system.
