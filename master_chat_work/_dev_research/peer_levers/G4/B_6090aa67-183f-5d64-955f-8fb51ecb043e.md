## 9. Writing style (how the spec states rules)
1. "Round-half-to-even is not this rule and produces a different ledger." (L46-47) Names the wrong route outright. This **leaks**; avoid it.
2. "The sort is global, not per event; matching each event to its own best prior in turn is a different procedure and pairs differently." (L605-606) Same leak.
3. "where two readings of a sentence would give different numbers, the sentence is wrong and this document is the thing to re-read" (L4-7) A completeness promise. The task broke it (two bare keys), and that break is where all the points came from.
4. "`magnitude_contributions` ... counts a magnitude whose site section 12.3 trimmed just like one that contributed, so that these counts sum to `magnitude_stations.reported`" (L719-722) Defines a count through a balancing identity. **Technique worth reusing:** state the definition as an invariant that must reconcile with another file, not as a recipe. Here it was applied to only one of two analogous keys.
