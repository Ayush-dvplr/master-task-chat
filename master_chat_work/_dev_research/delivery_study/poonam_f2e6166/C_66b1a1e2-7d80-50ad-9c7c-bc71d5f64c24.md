## 9. Take-aways
- SAFE: tests/ carries the generator plus the reference's output digests and no rule implementation, so the oracle and the expected values cannot be read back from tests.
- SAFE: one store per axis shift (encoding, names, revision, policy), with equality checks such as encshift == challenge. These are cheap mutation tests that grade "nothing rests on names or encodings".
- SAFE: a dedicated probe store full of stated edge rules whose shapes are absent from shipped data (W5). Any one miss voids the store. This is where the agent lost points.
- RISKY: a per-store spine gate voiding every leaf. It is stated in the instruction and QC accepted it as a WARN, but it is the CL-4 shape our playbook calls risky. It amplified 10 direct points to 52.
- RISKY: a hidden store that combines several axis shifts at once (eval). It works, but it hides which rule failed and makes the score hard to explain.
- AVOID: a verifier that saves no failure messages. It made the loss undiagnosable from the run folder (G7).
- AVOID: doc sentences that explain the trap and give a worked example (the escape rule). That is our ESC/EXT leak shape.
