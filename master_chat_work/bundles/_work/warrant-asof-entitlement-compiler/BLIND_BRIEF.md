## How to score a delivery on the final tests (Docker only)
Score harness: `WORK/harness/score.py` (loads `tests/test_output.py`, recomputes every graded check with a stub rewardkit, prints one line per check and a `## SCORE` line; positive weight 152).

```
W="/Users/mac/Desktop/Terminal Bench/master_chat_work/bundles/_work/warrant-asof-entitlement-compiler"
B="/Users/mac/Desktop/Terminal Bench/master_chat_work/bundles/warrant-asof-entitlement-compiler"
D=<blind's delivered out dir containing tool.zip and the artifacts>
N=<blind name>
docker ps   # at most 2 of these at once; check `sysctl vm.swapusage` used < 20 GB
nohup sh -c "perl -e 'alarm 3600; exec @ARGV' docker run --rm --name c6740572_blind_$N --memory 4g --cpus 2 \
  -e PYTHONDONTWRITEBYTECODE=1 -e DELIVERED=1 \
  -v '$W/harness':/h:ro -v '$B/tests':/tests:ro -v '$D':/prog:ro \
  python:3.12-slim python3 /h/score.py /prog > '$W/blinds/score_$N.txt' 2>&1; echo ALL_DONE >> '$W/blinds/score_$N.txt'" > /dev/null 2>&1 &
```

- `DELIVERED=1` scores the blind's own `/app/out` as delivered (artifacts and report.json as is); the held-out and convention checks always rerun the blind's tool.zip on corpora built inside the container.
- To score only a tool.zip (artifacts regenerated by running it, report.json synthetic, so `report_transcript_complete` is not meaningful): drop `DELIVERED=1` and mount the zip: `-v '<zip>':/prog/tool.zip:ro ... python3 /h/score.py /prog/tool.zip`.
- Expected run time: 15-25 minutes for a careful tool (each convention corpus build ~5-30 s; shipped calls up to a few minutes when the tool reads the observations).
