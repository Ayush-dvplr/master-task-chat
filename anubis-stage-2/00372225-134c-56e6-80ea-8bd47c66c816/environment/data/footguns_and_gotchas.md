# Known traps and footguns

The DRAFT grid sheet is not authoritative; select the LIVE sheet by the run profile tag. The flat coefficient archive and the prior recalibration shim are superseded. The scale scratch book is superseded. The prior tier weights file is superseded, so the tier objective weights come from the current tier weight book. The relaxation notes and the docx appendix restate retired governance values; the envelope is authoritative. The effective lot is the smaller of the two declared lots, not the larger, and it decides which batches are eligible. The recovery floor applies before reweighting. Rounding is staged, not once. QC-fail rows are excluded before ordering, and those excluded ids are what the excluded reading list reports. The matrix shift is added after the floor clamp and is a whole-unit offset.
