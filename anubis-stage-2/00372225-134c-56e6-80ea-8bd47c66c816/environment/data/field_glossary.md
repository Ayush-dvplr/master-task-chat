# Glossary

Analyte: a measured quantity. Matrix: a grouping of analytes carrying a matrix class, a tier, and a shift. Tier: routine or stat, each with an objective weight read from the current tier weight book. Matrix class: serum or whole_blood. Channel: the carry lane for spilled admission. Batch: a run window bounded by settle slots. Method: photometric, enzymatic, or potentiometric, selecting the exponent regime.
