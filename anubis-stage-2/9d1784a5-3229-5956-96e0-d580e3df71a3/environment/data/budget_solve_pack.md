# Heat-load budget solve pack v2.3 (as executed for the published budget)

## Steps

1. Load every file named rd_* in the data directory.
2. Drop every reading key that has a void copy, then keep the highest rev.
3. Window: readings from plateau start to plateau end inclusive.
4. Calibrate with the latest calibration sheet in the workbook; NTC in resistance.
5. Stage temperature: mean of all sensor readings; no spike or outlier screen.
6. Link heat flow: q = k(T_mean) * A / L * dT from K_TABLES_R2; joints ignored.
7. Intercepts at their nominal_K.
8. Loads: links plus harness by node_hint plus parasitic loads.
9. Capacity from CAPMAP_V1; no service derates.
