A package registry publishes its index as binary shards, and the platform team replays five benchmark workspaces against that index to plan the smallest install each workspace can take. Everything the registry published sits under `/app/data`: how a shard is laid out and which optional transforms its flag word can switch on, the registered names with their rename chains and licences, the workspace manifest and requirements, the identity, licence, resolution, feature and footprint policies, a calibration slice, the conventions for the derivation record and a report schema. Six registry constants were withheld from all of it. The calibration slice publishes a candidate list for each of the six and a set of control figures, and exactly one assignment of the six reproduces every one of those figures. The documents state every rule, but not the order in which the rules act on one another.

Deliver one program at `/app/out/optimize.py`. It takes a directory laid out like `/app/data` as its first argument and an output directory as its second, reads only the input directory it is handed, and writes nine JSON documents into the output directory. The same program will be run again over freshly built directories drawn from the same policies, each carrying its own withheld constants, its own shards and its own published figures, so every figure it writes has to come from the directory in front of it. Each run over one such directory has to finish within sixty seconds. Run it once over `/app/data` with `/app/out` as the output directory.

The nine documents are the lock plans of the five workspaces at `/app/out/scenario_visible.json`, `/app/out/scenario_peak.json`, `/app/out/scenario_steady.json`, `/app/out/scenario_burst.json` and `/app/out/scenario_latency.json`, the registry performance report at `/app/out/perf_report.json`, the bottleneck analysis at `/app/out/bottleneck_analysis.json`, the index integrity report at `/app/out/data_quality.json` and the derivation record at `/app/out/recommendations.json`. The report schema fixes the field names, value types and orderings of each one, and every document is written as JSON with two space indentation, keys in ascending order and a closing newline.

The derivation record is the account of the search. It carries a verdict for each of the sixty candidates with the falsifier of every rival, the falsifier totals, one row per published control holding the published and the reproduced figure, the settlement passes of every workspace and the licence divergence list, each counted the way the conventions document and the feature policy define it.

Five working rules bind how you get there. Each time you discard a candidate, state in the session which control figure it disagrees with, not only in the finished record. Write out the comparison of reproduced and published control figures before you read any field shard with the recovered constants. Before you settle any workspace, write out the governing licence family of every package whose rename chain carries more than one name. Once the last of the six constants is settled, remove every JSON document from `/app/out`, keep the program there, and produce all nine documents again in one clean run. Before you finish, run the program over a copy of `/app/data` placed in a directory with a different name and compare its nine documents with the ones in `/app/out`.

Use the Python 3 standard library alone. Leave everything under `/app/data` exactly as you found it. Do not look up solutions online.

You have 10800 seconds to complete this task.
