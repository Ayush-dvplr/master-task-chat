# unit reference
timeout stored: seconds
config unit: milliseconds
conversion: ms = seconds * 1000
then apply timeout_ms_delta
timeout_ms_delta cutover: 1650000000
timeout_ms_delta stored: whole seconds on an override row whose version has an effective_from in policy_version_map.json before the cutover, milliseconds on every other override row
timeout floor: the timeout starts at the base in milliseconds and takes the amount each applied override adds, one at a time in ascending seq; whenever the running value falls below 1000 it is raised to 1000 before the next amount
timeout floor example: a base of 3000 with added amounts -900, -900, -800 and +500 runs 2100, 1200, 1000, 1500
