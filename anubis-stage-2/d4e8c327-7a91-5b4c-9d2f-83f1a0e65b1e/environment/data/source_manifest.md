# Source manifest

Six record sources carry the Notice of Readiness population.

- nor_log_*.csv: NOR logs with the first laytime_hours column governing.
- fixed_width_intake_*.txt: fixed-width intake.
- registry_q*.tsv: registry quarters.
- state_events_p*.jsonl: NOR state events (ordered by version).
- port_circulars_p*.jsonl: amendments.
- approval_audit.log*: audit rotations.
