# NCA rerun pack (as executed for the published report, 2026-12-08)

The published report `be_report_published.csv` and `be_statistics_published.json` were produced by the
steps below from the LIMS staging schema. They are kept as they were run.

## Q01 Concentrations

```sql
SELECT tube, analyte, conc_ng_ml, flag FROM lims_concentration_cache WHERE run_status = 'ACCEPTED' AND flag <> 'DQC_FAIL'
QUALIFY row_number() OVER (PARTITION BY tube, analyte ORDER BY run_date DESC) = 1;
```

## Q02 Calibration (LIMS)

```sql
curve := linear_fit(target_nominal, response, weight => method_sheet_legacy.weighting); -- one exclusion pass
```

## Q03 Run status

```sql
JOIN run_status_dashboard USING (run_id) WHERE lab_status = 'ACCEPTED';
```

## Q04 BLQ

```sql
UPDATE conc SET value = lloq / 2 WHERE flag = 'BLQ';
```

## Q05 Times

```sql
SELECT tube, nominal_h AS t FROM tube_manifest_main;
```

## Q06 Profiles

```sql
GROUP BY subject, period, analyte ORDER BY t; -- unscheduled draws have no nominal and drop out
```

## Q07 AUC

```sql
auc_last := sum((t2 - t1) * (c1 + c2) / 2);
```

## Q08 Terminal phase

```sql
lambda_z := -slope(ln c ~ t over the last 3 points);
```

## Q09 AUCinf

```sql
auc_inf := auc_last + c_last_observed / lambda_z;
```

## Q10 Population

```sql
subjects with both periods present; no further exclusions
```

## Q11 Potency

```sql
value_T := value * 100 / 98.2; value_R := value * 100 / 101.4;  -- potency_certificates.xml
```

## Q12 Comparison

```sql
d := ln(T) - ln(R) per subject; ci := mean(d) +/- t(0.975, n - 1) * sd(d) / sqrt(n); -- stat_quick_reference.txt
```

## Q13 Decision

```sql
PASS when 80 <= lower AND upper <= 125 (unrounded)
```
