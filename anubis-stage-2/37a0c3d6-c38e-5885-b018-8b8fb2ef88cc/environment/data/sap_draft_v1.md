# VRX-BE-2614 statistical analysis plan, DRAFT v1 (2026-09-30)

Status: superseded by amendment A2 (see the governance memo).

## Pharmacokinetic parameters

- Nominal sampling times are used.
- Concentrations below the LLOQ are set to LLOQ/2.
- AUC by the linear trapezoidal rule; lambda_z from the last three quantifiable concentrations.
- AUCinf = AUClast + Clast(observed)/lambda_z.

## Statistics

- 90 % confidence intervals from z = 1.645.
- Subjects who vomit are kept.
